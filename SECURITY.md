# Politique de sécurité

Si vous suspectez une vulnérabilité :

1. Évitez la discussion publique.
2. Envoyez une description précise à `security@audire.app`.
3. Incluez : version de l’app, appareil, version OS, et pas d’attaque exploitée en production.

Réponse visée : 72 heures pour accusé de réception, puis tri selon criticité.
