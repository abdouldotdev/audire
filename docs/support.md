# Support Audire

Besoin d’aide avec un livre, une voix ou un modèle téléchargé ?

Ouvrez une demande sur le dépôt officiel :

- [Signaler un problème](https://github.com/abdouldotdev/audire/issues/new?template=bug_report.md)
- [Proposer une amélioration](https://github.com/abdouldotdev/audire/issues/new?template=feature_request.md)

N’ajoutez jamais un livre, un passage de livre, une clé ou une information personnelle à une demande publique.

Pour la confidentialité, consultez la [politique de confidentialité](./legal/privacy.md).
